# 두 정수의 합 (예시 문제)

> 로컬 저지 사용법 확인용 예시 — 실사용 시작하면 이 폴더를 삭제하고 본인 문제를 추가할 것.
> 채점: `python ../../judge.py 문제/_example` (예제 실행) / `--submit` (전체 채점)

## 문제 설명

두 정수 `a`, `b`가 주어질 때 두 수의 합을 return 하도록 solution 함수를 작성하세요.

## 제한사항

- -1,000,000 ≤ `a`, `b` ≤ 1,000,000

## 입출력 예

| a | b | result |
|---|---|---|
| 1 | 2 | 3 |
| -5 | 5 | 0 |

## 새 문제 추가 방법

`문제/<슬러그>/` 폴더에 3종 파일을 만들면 된다:
1. `문제.md` — 문제 설명 (프로그래머스식)
2. `solution.py` — `def solution(...)` 기본 템플릿
3. `testcases.json` — `{"timeout_sec": 초, "examples": [{"input": [인자들], "output": 기댓값}], "grading": [... + "kind": "정확성"|"효율성"]}`

훈련 원칙: grading 케이스는 열어보지 않는다(실전과 같은 블라인드 채점). Claude에게 "이 문제 채점 케이스 만들어줘"라고 하면 브루트포스 대조로 생성해 준다.
